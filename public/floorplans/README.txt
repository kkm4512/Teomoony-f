평면도 이미지 넣는 곳  (2026-10-18)

  public/floorplans/<단지코드>/<전용면적>.jpg
  예) public/floorplans/49101/84.94.jpg
      public/floorplans/49101/59.99.png

규칙
  * 폴더 이름 = 단지코드(complex_id). 화면이 알려준다.
  * 파일 이름 = 전용면적 소수 둘째 자리까지. 화면의 평형 칩과 같은 수다.
  * 같은 면적에 타입이 여럿이면 뒤에 붙인다:  84.94_A.jpg, 84.94_B.jpg
  * jpg / png / webp / svg 를 읽는다.

왜 이렇게 하나
  평면도는 **그림일 뿐 좌표가 아니다.** 면적이나 치수를 여기서 뽑아 쓰지
  않는다. 보여주기 전용이다. 그래서 DB 에 넣지 않고 파일로 둔다 -
  넣고 빼는 데 적재기도 마이그레이션도 필요 없다.

출처를 지킬 것
  남의 사이트(네이버 등)에서 가져온 이미지를 넣지 않는다.
  분양 모집공고문(공개 문서), 건설사가 배포한 자료, 직접 만든 그림을 쓴다.
